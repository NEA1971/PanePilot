PanePilot für Windows – portable Version
========================================

Starten: Ordner entpacken und PanePilot.exe doppelklicken. Es wird nichts
installiert. Einstellungen liegen unter %APPDATA%\PanePilot.

Lieber mit Startmenü-Eintrag und Deinstallation? Dann das Setup nehmen:
PanePilot-<Version>-windows-x64-setup.exe (auf derselben Release-Seite).

Beim ersten Start warnt Windows ggf. („Der Computer wurde durch Windows
geschützt“), weil das Programm nicht signiert ist:
„Weitere Informationen“ → „Trotzdem ausführen“.

Noch nicht unter Windows (folgt in 3.1): Video-Funktionen und Zusatzprogramme
(ffmpeg, exiftool, MKVToolNix, 7-Zip), „Danach“-Aktionen beim Synchronisieren.

PanePilot.exe. Settings are stored in %APPDATA%\PanePilot. For a Start menu

start because the program is not signed: “More info” → “Run anyway”.
