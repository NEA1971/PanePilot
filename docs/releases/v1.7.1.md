**PanePilot 1.7.1** – fixes in the meta wizard.

## Fixed
- **Custom fields that differ only in case are now one field.** In MKV files PanePilot writes custom fields in capitals (as usual for Matroska), so a field “Season” came back as “SEASON”. The meta wizard then showed two columns, and the one from the saved layout could no longer be switched on or off. Columns and sidebar now merge such fields.
- **Text file → tag:** the buttons below the **left** list (move up/down, insert/remove placeholder) acted on the right list.
- **Text file → tag:** CSV files with a **comma** as separator (the LibreOffice default) are now recognised, in addition to semicolon and tab.

## Help
- Examples for “file name → tag” (e.g. for series episodes `S01E09`) and how to save a table from LibreOffice Calc for “text file → tag”.

🇩🇪 **Behoben in 1.7.1:** Eigene Felder, die sich nur in der Groß-/Kleinschreibung unterscheiden (z. B. „Season“ und „SEASON“ bei MKV), sind jetzt ein Feld – die doppelte, nicht abwählbare Spalte ist weg. Bei „Textdatei → Tag“ wirken die Knöpfe unter der linken Liste wieder links, und CSV-Dateien mit Komma als Trenner werden erkannt. Die Hilfe enthält Beispiele für „Dateiname → Tag“ (z. B. Serienfolgen) und erklärt, wie man eine Tabelle aus LibreOffice Calc richtig speichert.
