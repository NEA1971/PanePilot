**PanePilot 3.0.0 – now also for Windows 10 and 11 (64-bit).**

## Windows
- **Setup** `PanePilot-3.0.0-windows-x64-setup.exe`: installs to `C:\Program Files\PanePilot` with a Start menu entry (desktop icon optional); uninstall via “Apps & features”. Or the **portable ZIP** `PanePilot-3.0.0-windows-x64.zip`: extract and start `PanePilot.exe`.
- Not code-signed: Windows warns on the first start – “More info” → “Run anyway”. Settings are stored in `%APPDATA%\PanePilot`.
- **Updates** work as on Linux; on Windows PanePilot downloads the new setup and starts it (portable: the new ZIP).
- **Recycle Bin**: show, restore, delete permanently, empty.
- **Open with**: the programs registered for the file type, plus the Windows “Open with” window.
- **This PC** in the folder tree with all drives and labels, network drives included; `\\server\share` paths in the path bar; **Map network drive / Disconnect** in the File menu and the folder tree.
- **Attributes** (read-only, hidden, archive, system) as a column and as a tab in the properties instead of Linux permissions.
- **Hidden files** by attribute and dot names; **protected system files** (e.g. NTUSER.DAT) only with a separate setting.
- **Passwords** in the Windows Credential Manager.
- **Clipboard** menu with 8.3 short paths, “web” paths with `/` and UNC paths.
- Coming in 3.1: video functions and helper tools (ffmpeg, exiftool, MKVToolNix, 7-Zip), “When finished” actions of synchronization, importing favourites from FreeCommander.

## Linux and Windows
- **Settings → General → Terminal**: choose which terminal “Open terminal here” starts (automatic, GNOME Terminal, Konsole, Windows Terminal, PowerShell, cmd or a custom command with `{folder}`).
