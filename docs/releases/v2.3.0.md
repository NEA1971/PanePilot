**PanePilot 2.3.0** – a tamed mouse wheel, more update options and Jellyfin-style IDs.

## Changed
- **Mouse wheel everywhere in PanePilot:**
  - Drop-down lists only react to the wheel while they are open. A closed list no longer jumps to the next entry – in the meta wizard this could even select “< remove >” – the wheel scrolls the page instead.
  - Sliders and number fields only react after you clicked them.
  - Lists, tables and text fields inside a scrollable page (e.g. “Existing backups” in the settings) scroll only themselves and no longer hand the wheel on to the page at their end.
- **Updates:** check automatically **Never** (default, as before), **Once a day** or **At every start**. New setting for the old AppImage file after an update: **Ask** (default), **Always move to the trash** or **Always keep** (hidden for .deb/.rpm installs).
- **Archives:** the setting is now a single checkbox “Open archives with the default application”; an earlier choice is kept.

## New
- **IDs in file and folder names like Jellyfin:** `[imdbid-tt…]`/`[imdb-…]`, `[tmdbid-…]`/`[tmdb-…]` and `[tvdbid-…]`/`[tvdb-…]`, in `[]`, `()` or `{}`, several per name.
  - Movies: in the file name or the folder directly above (`Alien (1979) [imdbid-tt0078748]/Alien.mkv`).
  - Series: IMDb and TVDB IDs as well as TMDB IDs on the series folder, the season folder (`Season 01 [tvdbid-…]`) or the episode file; an episode's own IMDb ID leads to its series.
  - A bare number such as `[tt0407362]` is not recognised – as in Jellyfin.
  - New help section “File names and IDs”.
