**PanePilot 1.6.3** – no more waiting with many selected files.

## Fixed
- **PanePilot froze for a long time when a folder with many selected files was reloaded** – for example when closing the meta wizard after selecting all videos. The selection was restored file by file, and the status bar was recalculated after each one. It is now restored in one step: with 1500 selected files this takes a moment instead of more than a minute.

## Changed
- **Meta wizard status text**: instead of always “Looking for music files …” it now says “Looking for files …” and shows what was found, e.g. “432 music files and 3246 pictures found”.
- **New meta wizard icon**: a box with “</>” instead of the music note, because the meta wizard now handles music, photos and videos.
