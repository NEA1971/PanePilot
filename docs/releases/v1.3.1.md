**PanePilot 1.3.1** – fixes for the FTP/SFTP client.

## Fixed
- After connecting or changing folders on a server, “Connecting …” / “Reading folder …” windows could stay on screen although the folder was already shown; “Cancel” did nothing and they were hard to close. Waiting windows now only appear for slow requests and always disappear when the request is done.
- Waiting windows are independent windows again: moving them no longer moves the main window (GNOME).

## Changed
- “Server” is now called “FTP server” in the sidebar, menus, settings and help (e.g. *File ▸ FTP server manager …*).

Behoben; Wartefenster erscheinen nur noch bei langsamen Abfragen und lassen sich unabhängig vom Hauptfenster verschieben. „Server“ heißt jetzt überall „FTP-Server“.
