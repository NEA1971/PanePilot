**PanePilot 3.0.1 – fixes from the first Windows test, network shares on Windows.**

## Windows
- **Trash button** in the button bar works: click opens the Recycle Bin, right-click offers open/empty, files can be dropped on it; an orange dot shows a full Recycle Bin.
- **Open terminal here** opens a real console window (cmd, PowerShell, Windows Terminal – also when installed from the Store).
- **Network:** typing `\\server` into the path bar lists the server's shares as folders; the folder tree has a new **Network** entry with the computers Windows finds and servers you add yourself (right-click → “Add server …”). Each server appears only once. If a login is needed, the Windows login window opens (with “Remember my credentials”). Right-click a share → “Map as network drive …”.
- New setting **File view → Network → Search the network in the folder tree** (on by default).

## Linux and Windows
- **Backups from the other system:** restoring a Linux backup on Windows (or vice versa) asks whether to apply the settings only – favorites, last folders, sync profiles and servers then stay as they are.
