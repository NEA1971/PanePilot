**PanePilot 3.3.0 – favorites menu on Alt+↑.**

- New **Favorites menu** (Alt+↑, like in FreeCommander; also in the Favorites menu): shows the favorites of the active side's set as a drop-down menu at the active panel – favorite folders as submenus, separators as lines, fully usable with the keyboard. Folders open in the active panel, files with their default program. The key can be changed under Settings → Shortcuts. Thanks to rbrtk2025 for the suggestion (discussion #3).
