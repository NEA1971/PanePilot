**PanePilot 1.23.1** – tidier toolbar.

## Changed
- The clipboard entries (file path, file name, folder path, details …) are no longer offered as separate toolbar buttons; they live only in the arrow menu of the **Copy** button, with the normal copy at the top – like the View and Filter buttons. Buttons you had added are removed automatically. The Edit menu and the right-click menu keep the “To clipboard” submenu.

---

🇩🇪 **Neu in 1.23.1:** Die Zwischenablage-Einträge gibt es nicht mehr als eigene Knöpfe, sondern nur im Pfeil-Menü des Knopfs „Kopieren“ – oben das normale Kopieren, darunter die Pfad- und Namens-Einträge. Bereits angelegte Knöpfe verschwinden automatisch.
