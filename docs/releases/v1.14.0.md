**PanePilot 1.14.0** – subtitles from OpenSubtitles, adding subtitle files, MTS → MKV and a better online search.

## New
- **Search subtitles …** (video mode): searches opensubtitles.com for the selected videos – by file fingerprint and IMDb/TMDB ID (series with season and episode), otherwise by title and year. One group per video with language, release, downloads, rating and the flags “exact match”, “forced” and “hearing impaired”; the best hit per language is preselected, the remaining daily downloads are shown.
  - Saved next to the video in Jellyfin style: `Film.eng.srt`, `Film.eng.forced.srt`, `Film.eng.sdh.srt`.
  - Optional **“Add directly to the video”** (MKV and MP4), as a new “…-Copy” or replacing the original.
  - Setup under **Settings → Meta wizard → Subtitles (OpenSubtitles)**: your own API key (“API Consumers”), optional username and password for more downloads per day, languages (default `de, en`). Key and password are only stored in the keyring.
- **Tracks … → Add subtitles …** (single video): matching subtitle files from the folder are offered (e.g. `Film.eng.srt` for `Film.mkv`), others via a file dialog. Language and “forced” come from the file name and can be changed. Saved as “…-Copy” or replacing the original; the subtitle file stays. MP4: text subtitles are converted, image subtitles only fit into MKV. Windows-1252 SRT files are recognised.
- **Change format …** now also converts **MTS and M2TS** (camcorder) to MKV.
- **Online data:** if nothing is found, PanePilot searches again with umlauts (ae → ä, oe → ö, ue → ü, ss → ß) and then without the year. In the overview, **“Search manually …”** for movies that were not found (title, year or ID) and **“Search for a different film …”** via right-click (for series: the whole series).
- **New fields** (TMDB only, proposals like all others): `Actors` (first 5 cast members), `Rating` (e.g. `7.8`), `Certification` (age rating for the country of the program language, e.g. `FSK 12`).

## Changed
- The tick “Save subtitles as files before removing” is remembered.

🇩🇪 **Neu in 1.14.0:** „Untertitel suchen …“ lädt Untertitel von OpenSubtitles herunter (je Sprache der beste Treffer vorgewählt, Speichern im Jellyfin-Stil, auf Wunsch direkt ins Video). In „Spuren …“ holt „Untertitel hinzufügen …“ vorhandene Untertiteldateien ins Video. „Format wechseln …“ kann MTS/M2TS nach MKV wandeln. Die Online-Suche versucht es bei „nicht gefunden“ mit Umlauten und ohne Jahr; dazu „Manuell suchen …“ und „Anderen Film suchen …“. Neue Felder `Actors`, `Rating`, `Certification`. Einrichtung unter Einstellungen → Meta-Wizard → „Untertitel (OpenSubtitles)“.
