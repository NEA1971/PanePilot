**PanePilot 1.23.0** – view button, paths to the clipboard, smoother updates.

## New
- **“View” toolbar button:** a click switches between details and the last icon size; the arrow offers large, medium and small icons and details, with a dot at the current view. The button shows the current view. The former separate icon-view buttons are replaced automatically (menu entries and Ctrl+Shift+I stay).
- **Paths and names to the clipboard:** the “Copy” button now has an arrow menu (also in the Edit menu and the right-click menu under “To clipboard”): file path (Alt+Ins), file name (Alt+Shift+Ins), file name without extension, folder path, file path as `file:///` address and details (name, size, date, type – tab-separated, ready for spreadsheets). Several selected files give one line each.
- **New icon** for “Shared sidebar”.

## Fixed
- **Update with “Later”:** after downloading a new version, the launcher in the application menu and taskbar now points to the new file right away, so the next start no longer opens the previous version. At the first start of the new version PanePilot asks once whether the old file should go to the trash.
