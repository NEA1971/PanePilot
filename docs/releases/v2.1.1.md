**PanePilot 2.1.1** – open folders in a new tab from the context menu.

## New
- **“Open in new tab”** in the context menu of folders. With several folders selected, each one opens in its own tab, in the order of the list; the first new tab becomes active. The entry can be given a shortcut in the settings.

---

🇩🇪 **Neu in 2.1.1:** Im Kontextmenü von Ordnern gibt es „In neuem Reiter öffnen“. Sind mehrere Ordner markiert, bekommt jeder einen eigenen Reiter (in der Reihenfolge der Liste); der erste neue Reiter wird aktiv. Ein Tastenkürzel lässt sich in den Einstellungen vergeben.
