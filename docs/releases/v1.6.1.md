**PanePilot 1.6.1** – faster reading of MKV videos.

## Fixed
- **Reading MKV videos with an embedded cover image was very slow** in the meta wizard (and in the “Metadata” tab of the properties): to get the cover, PanePilot used ffmpeg, which read the entire video file – several gigabytes per film, which takes minutes over a network share. PanePilot now reads the attachments directly from the MKV file and only touches a few kilobytes plus the image itself.

---

🇩🇪 **Behoben in 1.6.1:** Das Einlesen von MKV-Videos mit eingebettetem Cover war im Meta-Wizard (und im Reiter „Metadaten“ der Eigenschaften) sehr langsam: Für das Cover hat ffmpeg jedes Mal das ganze Video gelesen – mehrere Gigabyte je Film, über das NAS dauert das Minuten. PanePilot liest die Anhänge jetzt direkt aus der MKV-Datei und braucht dafür nur wenige Kilobyte plus das Bild selbst.
