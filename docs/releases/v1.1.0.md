**PanePilot 1.1** – terminal, directory listings, scaling and application-menu integration.

## New
- **Open terminal here** – in the File menu and in the context menu of the file panel and the folder tree. Opens the system's default terminal in the shown folder or in the folder you right-clicked.
- **Create directory listing …** – writes an indented list of a folder with sizes and modification dates to a text file. Depth, files, hidden entries and “open afterwards” are selectable; columns stay aligned at any depth.
- **UI scaling** from 50 % to 200 % (*Settings ▸ General ▸ Display*), e.g. for UHD screens. Takes effect after a restart, which PanePilot offers right away.
- **Add to application menu** (*Settings ▸ General ▸ Display*): creates a launcher with the PanePilot icon that you can pin to the dock. When you start a newer AppImage later, the launcher is updated automatically.
- **Delta updates**: the AppImage now contains update information. Tools like AppImageUpdate or Gear Lever only download the changed parts (`.zsync` file in the release).
