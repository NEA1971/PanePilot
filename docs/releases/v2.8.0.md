**PanePilot 2.8.0** – write to archives, real conflict detection for saved synchronizations.

## New
- **Write to archives** (ZIP and TAR without extra programs, 7z with 7-Zip; RAR stays read-only): inside an opened archive, **F5** or dragging from the other panel copies files in (same names bring up the usual conflict question), **F6** moves in (originals go to the trash) or out (extract, then delete in the archive), **F7** new folder, **F2** rename, **F8**/Del delete – permanently, after asking. PanePilot writes a copy next to the archive first and only replaces the original when everything worked; errors or cancelling leave it unchanged. Password-protected archives can be written via 7-Zip with the password you entered.
- **Write back:** if you open a file from an archive and save it, PanePilot asks whether to write the change back into the archive (while PanePilot is running).
- **Real conflict detection for saved synchronizations:** after each error-free run PanePilot remembers the state of both sides (in its settings, not in the synced folders). Next time a file changed on one side only wins even if its time is older; changed on both sides is a **conflict**; in two-way mode a file deleted on one side is deleted on the other side too (trash) instead of being copied back; in one-way mode (also mirror) a changed target is shown as a conflict instead of being overwritten. New states “changed on both sides”, “deleted on the left/right”, with a tooltip showing what changed. Skipped conflicts are reported and stay detectable.

- **In Archive schreiben** (ZIP, TAR, 7z mit 7-Zip; RAR nur lesbar): F5/Ziehen hinein, F6 hinein bzw. heraus, F7 neuer Ordner, F2 umbenennen, F8 endgültig löschen. Geschrieben wird erst in eine Kopie, das Original wird nur bei Erfolg ersetzt.
- **Zurückschreiben:** Aus einem Archiv geöffnete und gespeicherte Dateien – PanePilot fragt, ob die Änderung zurück ins Archiv soll.
- **Echte Konflikterkennung** bei gespeicherten Abgleichen: gemerkter Stand nach jedem Lauf; „auf beiden Seiten geändert“ ist ein Konflikt, Löschungen werden in der Richtung „beide“ übernommen, ein verändertes Ziel wird nicht mehr einfach überschrieben.
