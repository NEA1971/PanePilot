**PanePilot 1.14.1** – fix for MKV tags.

## Fixed
- **MKV:** Some files store their movie tags with the target type “MOVIE” but without the numeric target level (e.g. files once created with ffmpeg). PanePilot wrote year, IDs and other custom fields correctly but did not read them back, so they seemed to disappear after saving. They are now read as movie tags.

---

🇩🇪 **Korrektur in 1.14.1:** Bei manchen MKV-Dateien verschwanden nach dem Speichern scheinbar Jahr, `imdbid`, `themoviedb` und weitere eigene Felder. Sie waren in der Datei, wurden aber nicht wieder eingelesen, weil die Tags dort nur mit „MOVIE“ statt mit der Zielebene 50 gekennzeichnet sind. Jetzt werden sie richtig gelesen.
