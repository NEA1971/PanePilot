**PanePilot 1.7.3** – custom fields in “file name → tag”.

## Fixed
- **File name → tag with custom fields:** a placeholder such as `%Season%` was turned into “season”, so the values did not end up in the existing field “Season” and the column stayed empty. Custom field names now keep their spelling, and placeholders are matched to existing custom fields regardless of upper and lower case.
- Pending values of a custom field are found regardless of upper and lower case, so the column shows them before saving.

---

🇩🇪 **Behoben in 1.7.3:** Bei „Dateiname → Tag“ wurde aus einem Platzhalter wie `%Season%` „season“ – die Werte landeten nicht im vorhandenen Feld „Season“, die Spalte blieb leer. Eigene Feldnamen behalten jetzt ihre Schreibweise und werden unabhängig von Groß-/Kleinschreibung dem vorhandenen Feld zugeordnet.
