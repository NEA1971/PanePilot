**PanePilot 2.1.0** – tabs and recently visited folders.

## New
- **Tabs in both panels:** Ctrl+T opens a new tab with the current folder, Ctrl+W closes it, Ctrl+Tab / Ctrl+Shift+Tab switch. A new tab also opens with the middle mouse button or Ctrl+double-click on a folder and by double-clicking the empty tab bar; the middle button on a tab closes it, and tabs can be reordered by dragging.
  - Every tab keeps its own folder, back/forward history, sorting, filter and view (details or icons).
  - Right-click a tab: new tab, close, close others, lock/unlock, open in the other panel. A **locked tab** stays put – changing the folder opens a new tab instead.
  - The tab bar appears from the second tab on (or always: Settings → File view → Tabs). Tabs are locked while search, multi-rename, the meta wizard, synchronization or a server connection are active. All tabs are remembered on exit.
- **Recently visited folders:** the arrow at the right of the path bar (Alt+↓) lists the last 20 folders of both panels, newest first, remembered across restarts.

## Changed
- The **meta wizard** moved to **Ctrl+Shift+T**, because Ctrl+T now opens a new tab (configurable in the settings).
