**PanePilot 1.4** – photo metadata in the meta wizard.

## New
- **Photos in the meta wizard**: the meta wizard now shows and edits photo metadata (EXIF, IPTC, XMP) with the same table, sidebar, green pending changes, “Save tag” and undo as for music. If a folder contains music and photos, a **“Music | Photos”** switch appears; the kind with more files is preselected.
- **Formats**: JPEG, PNG, TIFF and WebP are read and written. HEIC/HEIF is written when **exiftool** is installed (`sudo apt install libimage-exiftool-perl`), otherwise read-only. RAW files (CR2, CR3, NEF, ARW, DNG, ORF, RW2 …) are read-only.
- **Fields**: title, description, keywords, rating (0–5), author, copyright and date taken can be edited and are written to all usual places (XMP, IPTC, EXIF – like digiKam). Camera, lens, exposure, aperture, ISO, focal length, flash, orientation and GPS are shown and can be removed with “< remove >” (e.g. to strip the GPS position before sharing). “Show on map” opens the position in OpenStreetMap.
- **Custom fields** for photos are stored as XMP in a separate “PanePilot” namespace.
- **Preview** of the selected photo in place of the cover.
- **Converters for photos**: tag → file name, file name → tag, tag → tag, text/CSV export and import; new placeholders such as `%datetaken%`, `%camera%`, `%width%`, `%height%`.
- **New function `$date(…)`**: e.g. `$date(%datetaken%,JJJJ-MM-TT_hhmmss)` → `2026-11-08_150012`; falls back to the file’s modification date.
- **Shift date …**: moves the date taken of several photos by days, hours, minutes and seconds (wrong camera clock, time zones), with explanation and preview.
