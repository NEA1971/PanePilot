**PanePilot 1.13.0** – remove tracks, export subtitles, change video format.

## New
- **Remove tracks:** the dialog “Tracks …” has a new column **Remove** for audio and subtitle tracks (MKV and MP4).
  - A **new file** “…-Copy” is created next to the original; the original stays unchanged.
  - The video track and the last audio track cannot be removed; the default flag moves to the next remaining track.
- **Export subtitles:** before removing (ticked by default) or with the button **Export subtitles** without removing. Text subtitles become `.srt`, ASS `.ass`, image subtitles keep their format (`.sup`, `.idx`/`.sub`); names in Jellyfin style, e.g. `Film (2001).eng.forced.srt`.
- **Change format …:** MP4, M4V, MOV and AVI → MKV, MKV → MP4, without re-encoding.
  - New file in the same folder (`Film.mkv` next to `Film.mp4`, otherwise `Film-Copy.mkv`); the original stays unchanged.
  - Tags, custom fields, cover, track languages/names and chapters are carried over.
  - Files with image subtitles or DTS/TrueHD audio are skipped for MP4 and listed.
- All of this shows a confirmation with the total size, a progress bar with Cancel, and checks the new file before keeping it.

🇩🇪 **Neu in 1.13.0:** Im Dialog „Spuren …“ lassen sich Ton- und Untertitelspuren entfernen – es entsteht eine neue Datei „…-Kopie“, das Original bleibt. Neu ist außerdem „Format wechseln …“: MP4/AVI → MKV und MKV → MP4 ohne Neukodieren, mit Tags, eigenen Feldern und Cover.
