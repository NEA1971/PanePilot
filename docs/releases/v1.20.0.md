**PanePilot 1.20.0** – search inside documents, similar-name duplicates, online data without overview.

## New
- **Search inside documents:** the text search now also looks into PDF, Word (DOCX), Excel (XLSX), PowerPoint (PPTX) and LibreOffice files (ODT, ODS, ODP) – switchable with “Also search documents (PDF, Office)”, on by default. The tooltip of a hit shows the matching passage, for PDFs with the page number. Old DOC/XLS/PPT files and scanned PDFs without a text layer are not searched. Files over 100 MB are still skipped and listed.
- **Duplicates: e) Similar name** finds typos and different spellings, e.g. “Der.Pate_1972.mkv” and “Der Pate (1972).mp4”. A slider sets the similarity (70–100 %, default 85 %). Extension, case, punctuation and IDs like `[imdbid-…]` do not count; numbers in the name must match, so “IMG_0001” and “IMG_0002” stay apart. Similar-to-similar names end up in one group.
- **Online movie data without overview:** in Settings → Meta wizard → Online data you can now choose to skip the overview and either fill only empty fields or overwrite everything (including the poster). With several matches the selection list still appears; at the end a short message shows how many movies were applied, not found or skipped. Values are marked green as before and written only with “Save tags”.
