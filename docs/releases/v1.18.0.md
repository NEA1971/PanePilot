**PanePilot 1.18.0** – synchronizing folders in the main window.

## Changed
- **Synchronize folders** no longer opens a separate window. The main window switches to a **comparison view**: the “Synchronize” sidebar with all settings on the left, the two folders side by side like two explorer windows, rows of both sides at the same height.
  - Folders as a **tree** with + / − (expanded after comparing); folders without differences are hidden.
  - **Middle column** with only the action symbol per row (→ ← ✕ ! – and • for mixed folders), the text as a tooltip; below it five symbol buttons for the selected rows. An action on a folder applies to everything inside.
  - Function keys in this view: F1 help, F5 start, F8 delete selected rows on the right. Double-click opens the file of the clicked side. Esc or the sidebar’s ✕ returns to the normal view.
  - The FreeFileSync import/export is now a “FreeFileSync” menu button in the sidebar.

---

🇩🇪 **Neu in 1.18.0:** „Ordner synchronisieren“ läuft jetzt im Hauptfenster: links die Seitenleiste mit allen Einstellungen, daneben beide Ordner als Baum mit + / −, die Zeilen beider Seiten auf gleicher Höhe und in der Mitte je Zeile das Symbol der Aktion (Text als Tooltip) samt fünf Knöpfen für die markierten Zeilen. F5 startet, F8 setzt „rechts löschen“, Doppelklick öffnet die Datei, Esc schließt die Ansicht.
