**PanePilot 1.13.2** – replace the original if you like.

## Changed
- **Tracks …:** new tick **“Replace original (no copy)”**. When removing tracks, the new file is checked and then replaces the original instead of being saved as “…-Copy”.
- **Change format …:** new tick **“Delete original afterwards”**. After a successful, checked conversion only the new file remains.
- Both are off by default and remembered; the confirmation clearly says that the originals cannot be restored. On an error or Cancel the original always stays.

🇩🇪 **Neu in 1.13.2:** In „Spuren …“ gibt es das Häkchen „Original ersetzen (keine Kopie anlegen)“, in „Format wechseln …“ das Häkchen „Original danach löschen“. Beides ist anfangs aus und wird gemerkt; das Original wird erst ersetzt bzw. gelöscht, wenn die neue Datei geprüft ist.
