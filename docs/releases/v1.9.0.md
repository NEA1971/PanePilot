**PanePilot 1.9.0** – online movie data in the meta wizard.

## New
- **“Online data (movies) …”** in the video mode of the meta wizard fetches title, year, genre, plot summary, director and poster for the selected videos.
  - **Which movie:** from the custom fields `imdbid` / `themoviedb`, from an ID in the file name in Jellyfin style (e.g. `[imdbid-tt0078748]`), or by searching title and year from the file name. With several matches you choose the right movie from a list.
  - **Sources:** TMDB with your own free API key (Settings → Meta wizard → Online data for movies), otherwise Wikidata without an account (no plot summary, no poster).
  - **Language:** the program language, with English as fallback.
  - **Overview before applying:** “field – current – new” per movie; by default only empty fields are filled. The values are marked green and only written with “Save tags”; “Undo” works as usual.
  - Missing IDs are added (`imdbid` ↔ `themoviedb`), a differing original title goes to `originaltitle`.
- The API key is only stored in the system keyring.

This product uses the TMDB API but is not endorsed or certified by TMDB.
