**PanePilot 3.1.0 – Windows part 2.**

## Windows
- **Favorites → Import from FreeCommander …** opens FreeCommander's settings folder with the newest `FreeCommander.fav*.xml` preselected. The favorites become a new favorite set “FreeCommander” (rename it like any set): categories as favorite folders (expanded/collapsed as before), folders and files with their names and font colour. Shortcuts, sorting and view settings are left out.
- **Video functions** (meta wizard videos, tracks, subtitles, MKV repair, ReplayGain) now work on Windows as soon as ffmpeg, exiftool and MKVToolNix are installed. PanePilot also finds them in their usual installation folders (Program Files, winget, Scoop, Chocolatey, `C:\ffmpeg\bin`) and starts them without a console window.
- **7-Zip** is found in `C:\Program Files\7-Zip`, so 7z archives and encrypted ZIPs work there too.
- **When finished** in synchronization: shut down and sleep via Windows; scripts `.bat`/`.cmd` run via cmd, `.ps1` via PowerShell, with the same `PANEPILOT_…` environment variables as on Linux.

## Linux and Windows
- New settings page **Additional programs**: shows for ffmpeg/ffprobe, exiftool, MKVToolNix and 7-Zip whether they were found, lets you set your own path (“Browse …”) and links to the download pages. The help explains which program is needed for what and how to install it.
