**PanePilot 1.0** – the first stable release. 🎉

PanePilot is a free two-panel file manager for Linux, inspired by FreeCommander. It brings together what usually takes several programs: file manager, multi-rename tool, music tag editor and checksum tool.

## Highlights
- **Two panels** with folder tree, nested favourites, drive overview (network shares, USB drives – also before they are mounted), filters, column profiles, single-panel view
- **File operations**: copy, move, rename, trash, archives, drag & drop, “Open with”, properties
- **Search** by name and content
- **Multi-rename** with placeholders, counters, dates, regular expressions, preview, profiles and undo
- **Meta wizard** for music tags (MP3, FLAC, Ogg, Opus, M4A, WMA, WAV): batch editing, covers, converters, text/CSV import and export, numbering, M3U8 playlists, **ReplayGain** (via ffmpeg)
- **Checksums** (CRC32, MD5, SHA-1/256/512) with comparison and checksum-file drag & drop
- **Configurable** shortcuts, function-key bar, toolbar and sidebars
- **Six languages** (English, German, Spanish, French, Russian, Franconian), editable in the settings
- **Built-in help** (F1), daily settings backup

## Installation
Download `PanePilot-1.0.0-x86_64.AppImage` below, make it executable and start it. Optional: `ffmpeg` for ReplayGain.
