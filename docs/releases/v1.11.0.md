**PanePilot 1.11.0** – video package: track editing and TV series data.

## New
- **Edit tracks (MKV):** the new button **“Tracks …”** in the video mode of the meta wizard shows all video, audio and subtitle tracks of the selected MKV files.
  - Change **language** (e.g. `und` → `ger`), **name** (shown by players like VLC instead of “Track 1”) and the flags **Default** and **Forced**.
  - **“Suggest names”** builds names like “German AC3 5.1”.
  - **Several videos at once:** tracks are grouped by number, a change applies to all selected videos; videos without the track are listed and skipped.
  - Written directly with mkvpropedit, in seconds and without rewriting the file (requires mkvtoolnix).
- **Online data for TV series:** “Online data (movies, series) …” now recognises episodes (`S01E02`, `s1e2`, `1x02`) and fetches episode title, summary, air year, genre and season poster from TMDB.
  - The series is identified from the folder (`Series/Season 1/…`, `Series (2008) [tmdbid-1396]/…`) or the file name and chosen **once per series**.
  - New custom fields `Series`, `Season` and `Episode` (two digits); in MP4 also the iTunes standard fields.
  - Rename episodes with tag → file name, e.g. `%Series% - S%Season%E%Episode% - %title%`.

This product uses the TMDB API but is not endorsed or certified by TMDB.
