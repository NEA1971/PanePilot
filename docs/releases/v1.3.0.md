**PanePilot 1.3** – FTP/SFTP client.

## New
- **Servers sidebar**: a new sidebar module (left or right, like the folder tree and favourites) lists your servers, grouped in folders and sortable with the mouse. Double-click connects; the server is shown in the normal file panel on the same side. Right-click: connect, disconnect, edit, copy, rename, delete, new server, new folder. A connected server is bold with a green icon, and the path bar shows its address (e.g. `sftp://user@host/path`).
- **Protocols**: FTP, FTP over TLS (explicit and implicit) and SFTP (SSH).
- **Server manager** (*File ▸ Server manager …*), laid out like FileZilla: protocol, host, port, encryption, logon type (normal, anonymous, ask for password, key file), user, password, background colour of the panel, comment, start folders, passive/active mode and character set.
- **Passwords** are stored in the system keyring (Secret Service, e.g. GNOME Keyring), never in the settings or backups. Without a keyring PanePilot asks when connecting.
- **Security**: SFTP host keys are confirmed on first contact with their fingerprint, and a changed key triggers a clear warning. Self-signed TLS certificates (e.g. phone apps) are confirmed once and pinned.
- **Working on the server**: download and upload with F5/F6 or drag and drop (whole folders included; moving deletes the source only after a successful transfer), rename, new folder, permanent delete with confirmation, refresh. Double-clicking a file opens a temporary copy with the default application. The connection ends with “Disconnect”, when you switch to a local folder in the same panel, or when you quit.
- **Transfer window**: folders are read completely first and processed as a list of files with overall progress, speed, time left and per-file status. New transfers are appended to the queue; pause/resume, cancel all, remove waiting entries and retry failed ones. The usual overwrite/skip/rename question appears for existing files. Optional: close automatically after a successful run.
- **Import from FileZilla** (*Settings ▸ General ▸ Servers*): takes over FileZilla’s server list including folders and saved passwords; existing servers with the same name are skipped.

## Notes
- Plain SCP is not supported; almost every SSH server also offers SFTP.
- Copying directly from server to server is not possible yet.
