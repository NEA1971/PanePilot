**PanePilot 1.18.1** – improvements to the comparison view.

## Changed
- **Synchronize folders:** folders that exist on one side only can now be expanded with + / − like all other folders; double-clicking a folder expands or collapses it instead of opening the file manager. Actions on single items inside such a folder are respected (e.g. keep one file).
- The **middle column** now runs down to the bottom of the list.
- Folder and file choosers of the comparison view open as **separate windows** again.
- **Meta wizard:** closed with the ✕ in its title row (like the synchronize sidebar) instead of a “Close” button.

---

🇩🇪 **Neu in 1.18.1:** Ordner, die nur auf einer Seite liegen, lassen sich jetzt aufklappen; ein Doppelklick auf einen Ordner klappt ihn auf bzw. zu statt Nautilus zu öffnen. Die Mittelspalte geht bis nach unten durch, die Ordnerauswahl öffnet wieder als eigenes Fenster, und der Meta-Wizard wird wie das Synchronisieren über das ✕ in der Titelzeile geschlossen.
