**PanePilot 2.4.0** – meta wizard: edit by double-click, episodes without S01E01, list of applied films.

## New
- **Double-click a cell in the meta wizard list** to edit the value right there – for that one row. Enter applies, Esc cancels; as always nothing is written before “Save tag”.
  - Double-clicking the **file name** renames the file (the extension stays; duplicate names are refused).
  - For long texts (description, comment, lyrics) the double-click jumps to the field in the sidebar.
- **Episodes without “S01E01”:** files that are only called `1.mkv`, `2.mkv` … or `Folge 3`, `Teil 3`, `Episode 3`, `E03` are recognised as episodes of the series named by their folder – after asking once per folder (“Treat the 6 files in … as episodes 1–6 of season 1?”). In a `Season 2` folder they count as season 2.
- **Online data without overview:** the final message now lists for every file which movie or episode was applied (“Heat.mkv → Heat (1995)”), so wrong matches are easy to spot. Long lists open in a scrollable window.

🇩🇪 **Neu in 2.4.0 (Meta-Wizard):** **Doppelklick auf eine Zelle** bearbeitet den Wert direkt in der Liste (Enter übernimmt, Esc bricht ab, geschrieben wird erst mit „Tag speichern“); Doppelklick auf den Dateinamen benennt um, bei langen Texten geht es ins Feld der Seitenleiste. **Folgen ohne „S01E01“** (nur „1.mkv“, „Folge 3“ …) werden nach einer Rückfrage je Ordner als Folgen der Serie erkannt. **Ohne Übersicht** listet die Abschlussmeldung jetzt für jede Datei den übernommenen Film bzw. die Folge auf.
