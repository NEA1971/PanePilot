**PanePilot 2.5.0** – RAW metadata via XMP sidecars, a map for photos, repair of unfinished MKV files, more text functions.

## New
- **RAW photos (CR2, NEF, ARW, DNG …):** title, description, keywords, rating, author, copyright and date taken can now be edited. The RAW file itself stays untouched – the values go into an **.xmp sidecar** next to it (new ones Lightroom-style as `IMG_1234.xmp`; an existing `IMG_1234.CR2.xmp` from darktable/digiKam is used further). Values in the sidecar win when displayed. Camera, exposure and GPS data stay as they are.
- **Sidecars follow their RAW file** when copying, moving, renaming (F2, batch rename, meta wizard), duplicating and deleting.
- **Map:** photos (and videos) with a GPS position show a small map with one pin per selected file in the meta wizard sidebar and in the Properties window. Drag to move, mouse wheel to zoom, double-click to show all pins again. Map tiles come from OpenStreetMap and are cached; positions cannot be set on the map. “Open in browser” still opens openstreetmap.org.
- **Unfinished MKV files** (never finalised, e.g. an interrupted download – saving tags failed with “… no level 1 element …”): PanePilot now explains the problem and offers to rebuild the file with ffmpeg without re-encoding; the original goes to the trash and saving is tried again.
- **Text functions** for tag → tag / tag → file name: `$mid(%title%,5,12)` (12 characters from character 5) or `$mid(%title%,5)` (from character 5 to the end) and `$len(%title%)`, in addition to `$left`, `$right`, `$replace`, `$trim`, `$upper`, `$lower`, `$caps`, `$num`, `$if`. Now described in the help.

🇩🇪 **Neu in 2.5.0:** **RAW-Fotos** lassen sich bearbeiten – die Werte landen in einer **.xmp-Begleitdatei** (neu nach Lightroom-Art `IMG_1234.xmp`), die RAW-Datei bleibt unverändert; die .xmp wandert beim Kopieren, Verschieben, Umbenennen und Löschen mit. **Karte** in der Seitenleiste des Meta-Wizards und im Fenster „Eigenschaften“ mit einer Stecknadel je Foto (OpenStreetMap, Mausrad zoomt, Ziehen verschiebt). **Unvollständig abgeschlossene MKV-Dateien** werden erkannt und auf Wunsch mit ffmpeg neu aufgebaut. Neue Textfunktionen **`$mid`** und **`$len`** (z. B. `$mid(%title%,5)` = ab dem 5. Zeichen).
