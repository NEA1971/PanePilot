**PanePilot 2.7.0** – quick view, select by pattern, folder sizes, file comparison, dates and permissions.

## New
- **Quick view:** new button **“Quick view”** (magnifier over a sheet, next to “View”; also View → Quick view). The **other panel** shows the selected file and follows the cursor: text, images (mouse wheel zooms), PDF (all pages), videos (still + duration, resolution, tracks), music (cover + tags), **LibreOffice and Microsoft documents** (Writer/Word as text, Calc/Excel as tables with one tab per sheet, Impress/PowerPoint slide by slide). A second click or **Esc** brings the list back. No key by default – assign a function key or shortcut if you like.
- **Select by pattern:** **Num +** / **Num −** extend or reduce the selection by pattern (prefilled with the current file's extension, several patterns with `;`, recent patterns, optionally including folders), **Num \*** inverts the selection, **Alt+Num +** selects all files with the same extension. Also in the Edit menu.
- **Folder sizes:** **Space** on a folder shows its size in the Size column; **View → Calculate all folder sizes** (Alt+Shift+Enter) runs in the background, **Esc** cancels. Selection totals in the status line include them.
- **Compare files …** (right-click, File menu, Ctrl+Shift+C): two selected files – both in one panel or one on each side. Text side by side with coloured differences, synchronised scrolling, previous/next difference; PDF and Office documents by their text; other files “identical” or the first differing byte. In **Synchronise folders**, double-clicking a differing file opens the comparison.
- **Change date …** (right-click, File menu): set the modification date to a fixed date, now, the date taken (photos/videos) or a date in the file name, with a preview and “Include subfolders”.
- **Permissions:** Properties → Permissions now has “Also for subfolders and contained files”; folders keep the execute right so they stay accessible.

🇩🇪 **Neu in 2.7.0:**
- **Schnellansicht:** neuer Knopf (Lupe über einem Blatt) – das andere Fenster zeigt die markierte Datei: Text, Bilder, PDF, Videos, Musik und LibreOffice-/Microsoft-Dokumente. Esc oder ein zweiter Klick beendet sie.
- **Auswahl nach Muster:** Num + / Num − / Num \* und Alt+Num + (auch im Menü Bearbeiten).
- **Ordnergrößen:** Leertaste auf einem Ordner, „Alle Ordnergrößen berechnen“ mit Alt+Umschalt+Enter, Esc bricht ab.
- **Dateien vergleichen …:** zwei markierte Dateien nebeneinander mit farbigen Unterschieden; Dokumente über den Text; Doppelklick im Ordnerabgleich öffnet den Vergleich.
- **Datum ändern …** (festes Datum, jetzt, Aufnahmedatum, Datum im Dateinamen) und **Rechte auch für Unterordner**.
