**PanePilot 1.19.0** – icon view, last run of saved synchronizations, new icons.

## New
- **Icon view** (View → Icon view, Ctrl+Shift+I, also available for the toolbar): each panel can show its folder as large icons instead of a list and remembers its choice.
  - Three sizes (small, medium, large) via View → Icon size or Ctrl+mouse wheel.
  - **Thumbnails** for images, the first page of PDFs, embedded covers of music files and embedded posters of videos (otherwise a frame from the film). Thumbnails already in the shared cache `~/.cache/thumbnails` (also used by Nautilus and other file managers) are used at once; missing ones are created in the background and stored there.
  - Selecting, keyboard, copying, dragging and the context menu work as in the list; the name is shown below the picture on up to two lines. New menu View → Sort by.
- **Saved synchronizations remember their last run:** below the selection in the sidebar and in File → Saved synchronizations a green check (no errors) or a no-entry sign (errors or cancelled) with the date; the tooltip shows the numbers and the first error messages.

## Changed
- New, clearer toolbar icons for panels one above the other, duplicate, properties, settings backup / restore, FTP server manager, help, online help, check for updates and support PanePilot. The meta wizard icon is larger.
