**PanePilot 1.15.1** – fix for MKV tags.

## Fixed
- **MKV:** Saving failed with “<Tag> is missing the element <Simple>” for files that contain an empty tag section (e.g. for a single track, left behind by other programs). Such empty sections contain nothing and are now removed before writing.

---

🇩🇪 **Korrektur in 1.15.1:** Bei manchen MKV-Dateien schlug das Speichern mit „<Tag> fehlt das Element <Simple>“ fehl. Ursache war ein leerer Tag-Bereich in der Datei, den ein anderes Programm hinterlassen hatte. Solche leeren Bereiche werden jetzt vor dem Schreiben entfernt.
