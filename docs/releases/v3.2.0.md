**PanePilot 3.2.0 – appearance: light and dark, the same on Linux and Windows.**

## Linux and Windows
- New setting **Appearance** (Settings → General): **Like the system** (default, follows the light/dark setting of Windows or GNOME), **Light** or **Dark**. Light is the calm Linux look (grey window background, visible frames, clearly filled selection) – on Windows it replaces the glaring white Windows 11 look. Dark is the same look in dark grey. The selection uses the system's accent colour; favorite colours that are too dark are shown lighter in dark mode.
- **Font and size** for the whole interface, with a **Default** button (Windows: Segoe UI 10 pt, Linux: system font).
- **File lists:** vertical **grid lines** between the columns (on by default) and **alternating row colours** (off by default), both in Settings → File view.
- **Favorites → Sort by name** in the context menu of a favorite folder (everything below it, subfolders included) or of an empty spot (the whole set). Separator lines are section borders and stay in place. Order: folders first, favorites first or mixed.

## Windows
- Filled blue folder icons like on Linux instead of the thin outlines.
- The share list of a server (`\\server`) no longer shows “01.01.1970” as the modification date.
