**PanePilot 1.19.1** – small fix for the icon view.

## Changed
- **Icon view:** the “..” entry (one folder up) is no longer scaled with the icons. It stays a small row at the top, exactly as in the list; only the folder contents are shown as icons. Arrow up in the first icon row moves to “..”, arrow down goes back to the icons; Enter or a double-click on “..” opens the parent folder, and you can drop files on it.
