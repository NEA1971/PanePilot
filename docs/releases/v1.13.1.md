**PanePilot 1.13.1** – bug fix.

## Fixed
- **Removing tracks:** if the removed audio track was longer than the video, the new file is shorter than the old one. The check wrongly treated this as an incomplete file and discarded it. The check now compares the length of the video track instead of the whole file.

---

🇩🇪 **Korrektur in 1.13.1:** Beim Entfernen einer Tonspur, die länger als das Video war, wurde die neue Datei fälschlich als „nicht vollständig“ verworfen. Geprüft wird jetzt die Länge der Videospur statt der ganzen Datei.
