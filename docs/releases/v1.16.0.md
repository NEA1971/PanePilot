**PanePilot 1.16.0** – compare and synchronize folders.

## New
- **File → Compare folders** (Ctrl+Shift+V): compares the left and right folder and selects in both windows the files that only exist on that side or are newer there. Differences up to 2 seconds are ignored (USB sticks, NAS); optionally also exactly one hour (daylight saving) and optionally the content.
- **File → Synchronize folders …** (Ctrl+Shift+S):
  - left → right, right → left or both directions (newer wins), with subfolders, include/exclude filters.
  - Preview list with the planned action per file; select several rows and set the action for all of them (→, ←, delete right/left, do nothing).
  - Optional mirroring: extra items in the target go to the trash.
  - Conflicts (same date, different content) are left for you to decide.
  - Runs with progress, can be cancelled, summary at the end.
- **Saved synchronizations** (e.g. “Photos → NAS”) with all settings, also in **File → Saved synchronizations**.
- **When finished:** run a command or script (with `PANEPILOT_*` environment variables), suspend or shut down the computer (30-second countdown) – always or only without errors.

🇩🇪 **Neu in 1.16.0:** „Ordner vergleichen“ markiert die Unterschiede in beiden Fenstern. „Ordner synchronisieren …“ gleicht zwei Ordner ab – in eine oder beide Richtungen, mit Unterordnern, Filtern, Vorschau mit änderbarer Aktion je Datei (auch für mehrere Zeilen auf einmal), wahlweise Spiegeln (Papierkorb) und Konflikterkennung. Abgleiche lassen sich speichern und über „Datei → Gespeicherte Abgleiche“ aufrufen. Nach dem Beenden kann ein Skript laufen oder der Rechner in Bereitschaft gehen bzw. herunterfahren.
