**PanePilot 2.0.0** – now also available as installable packages.

## New
- **`.deb` package** for Debian 12/13, Ubuntu 22.04+ and Linux Mint – install by double-click or with `sudo apt install ./PanePilot-2.0.0-amd64.deb`.
- **`.rpm` package** for Fedora, openSUSE and RHEL/Rocky/Alma – `sudo dnf install ./PanePilot-2.0.0-x86_64.rpm` (openSUSE: `sudo zypper install ./PanePilot-2.0.0-x86_64.rpm`).
- Both install to `/opt/panepilot` with a menu entry and icon, and bring ffmpeg, mkvtoolnix and exiftool along as recommended tools. Remove with `sudo apt remove panepilot` / `sudo dnf remove panepilot`; your settings in `~/.config/PanePilot` stay.
- In the package version, **Check for updates** downloads the new package to your Downloads folder and opens it with the software installer. “Add to application menu” is hidden there, and an old menu entry of the AppImage version is offered for removal once.
- **About PanePilot** shows how PanePilot is installed.
- The **AppImage** stays available as before.
