**PanePilot 1.8.1** – metadata table in the properties dialog.

## Changed
- **Properties → Metadata** is now a table with the columns “Field” and “Value”.
  - Drag the divider between the columns to change the width; it is remembered. A double-click on the divider fits the width to the longest field name.
  - Long values and field names wrap, even without spaces (e.g. lists of e-mail addresses).
  - Copy with Ctrl+C (value) or via right-click: “Copy value” / “Copy row”.

## Technical
- pypdf updated to 6.21.4 (security fixes for reading crafted PDF files).
