**PanePilot 1.7** – audio tracks and subtitles of videos.

## New
- **Audio tracks and subtitles in the meta wizard**: two new optional columns in video mode show the languages of the tracks contained in a video, as stored in the file – e.g. `deu, eng` for audio and `eng (forced)` for subtitles; `?` means “no language set”. The columns can be sorted, so you quickly find e.g. all films without a German audio track.
- **Details on hover**: the tooltip lists every track with the language name, format and flags, e.g. “deu (German) – AC-3 5.1 – default”, “eng (English) – AAC stereo – “Commentary””, “eng (English) – SRT – forced”.
- **Properties → Metadata** shows the same detailed list for a video.
- **New placeholders** `%audiolang%` and `%sublang%` for the converters, e.g. for tag → text file/CSV.
- The information comes from ffprobe, which already runs when reading videos – loading is not slower. It is display only; editing track languages may follow later.
