**PanePilot 1.5** – video metadata in the meta wizard.

## New
- **Videos in the meta wizard**: the meta wizard now shows and edits video metadata with the same table, sidebar, green pending changes, “Save tag” and undo as for music and photos. The switch at the top is now **“Music | Photos | Videos”**; the kind with the most files is preselected. Files ending in `.mp4` always count as video, `.m4a` stays music.
- **Formats**: MP4, MOV, M4V, 3GP and WMV are read and written. MKV and WebM are written when **mkvtoolnix** is installed (`sudo apt install mkvtoolnix`), otherwise read-only. AVI and MTS/M2TS (camcorders) are read-only.
- **Fields**: title, description, author, copyright, genre, year and custom fields can be edited. Date taken and GPS are shown; for MP4/MOV the date can be changed and GPS removed with **exiftool**, for MKV/WebM mkvtoolnix changes the date. “Show on map” opens the position in OpenStreetMap.
- **Technical information** via ffprobe (part of ffmpeg): duration, resolution, frame rate, video and audio codec, bitrate – as columns and placeholders.
- **Thumbnail (poster)**: the sidebar shows the thumbnail stored in the video, or a still frame from the video if there is none. The thumbnail can be replaced, removed or saved; “Use still frame as thumbnail” stores the frame shown in the video.
- **Converters for videos**: as for photos, including **Shift date …**; new placeholders `%duration%`, `%resolution%`, `%width%`, `%height%`, `%fps%`, `%codec%`, `%format%`. Default template for tag → file name: `$date(%datetaken%,JJJJ-MM-TT_hhmmss)`.
- **New help chapter “Additional programs”**: lists ffmpeg, exiftool, mkvtoolnix, 7-Zip and rar/unrar – what PanePilot uses them for, what is missing without them and how to install them. Notes about a missing program in the meta wizard link to this chapter.

## Fixed
- Undo after adding a cover to a file without one now also removes the cover again.
