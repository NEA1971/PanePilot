**PanePilot 3.2.1 – no more hangs on Windows.**

## Windows
- PanePilot no longer freezes when a network drive or server is not reachable (e.g. a company network without VPN, a switched-off NAS): the recycle bin indicator only checks local drives, network drive names come from the connection, favorites on network paths are checked in the background, and a server's shares load in the background.
- Network folders are no longer watched for changes (that could hang for seconds when leaving them); press F5 to refresh. Local folders still refresh automatically.

## Linux and Windows
- Alternating row colours are clearly visible in light and dark mode.
- Switching between light and dark no longer asks for a restart – the icons are recoloured right away, also when the system itself switches.
