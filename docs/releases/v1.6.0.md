**PanePilot 1.6** – find duplicates.

## New
- **Find duplicates** (File → Find duplicates …, or right-click a folder) in a separate window, while PanePilot stays usable. Three ways to define a duplicate:
  - **a) same content** – byte-identical files (size first, then SHA-256 only for files of equal size),
  - **b) same name without extension** – e.g. `Alien (1979).mkv` and `Alien (1979).mp4`,
  - **c) same name and same size** – fast, without checksum.
  A note explains which option is fast and which one may take long (large files, network shares).
- **Where and what**: start folder, depth 1 to 10 levels or unlimited, optionally also the folder of the other panel; filter such as `*.mp4;*.mkv` and a minimum size.
- **Progress** with the amount read so far and **Cancel**.
- **Result** in groups with name, folder, size and date, plus a summary of the surplus files and their size.
- **Check** files individually or with “all except the newest / oldest / largest”, **move them to the trash** (with a clear warning if no file of a group would remain), **show** a file in the panel and **save the list** as a text file. Permanent deletion is deliberately not offered.
- The last settings and the window size are remembered. The action has no default key but can be assigned under Settings → Keyboard shortcuts.

🇩🇪 **Neu in 1.6: Duplikate suchen** (Datei → Duplikate suchen … oder Rechtsklick auf einen Ordner) in einem eigenen Fenster. Drei Arten: **gleicher Inhalt** (Prüfsumme), **gleicher Name ohne Endung** (z. B. Film als MKV und MP4) und **gleicher Name und gleiche Größe**, mit Hinweis zur Geschwindigkeit. Einstellbar sind Ordnertiefe, der Ordner des anderen Fensters, ein Dateifilter und eine Mindestgröße. Die Treffer stehen in Gruppen; Dateien lassen sich ankreuzen („alle außer der neuesten/ältesten/größten“), in den Papierkorb verschieben, im Dateifenster zeigen und als Liste speichern.
