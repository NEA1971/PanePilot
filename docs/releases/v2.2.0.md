**PanePilot 2.2.0** – archives like folders, one “Archive” button and one “Tabs” button.

## New
- **Open archives like folders:** double-click or Enter on a zip, tar (.gz/.bz2/.xz), 7z or rar archive shows its contents in the panel – path e.g. `…/Photos.zip/Holiday`, “..” leads back out, back/forward and tabs work as usual.
  - Open files inside (they are extracted to a temporary folder; changes are not written back).
  - Copy files and folders to the other panel with F5 or by dragging – that extracts them, with the usual conflict dialog.
  - Archives are read-only: deleting, renaming, copying into them and new folders are not possible.
  - Password-protected archives ask for the password (not stored). AES-encrypted ZIPs, 7z and rar need 7zip (rar alternatively unrar).
  - Large archives show a progress window with Cancel while their contents are read.
  - Setting: double-click opens archives in PanePilot (default) or with the default application (Settings → File view → Archives).
- **“Archive” button** with arrow menu: Open · Extract here · Extract to … · Extract to “name” · Create archive …. Clicking the button opens the selected archive, or starts “Create archive …” when none is selected. The same entries are in the right-click menu under “Archive ▸”.
- **“Tabs” button:** clicking it switches “always show the tab bar” on and off; the arrow menu has Open in new tab · New tab · Next tab · Previous tab · Close tab · Lock tab.

## Changed
- The separate toolbar buttons for compressing/extracting and for the tab functions were replaced by the two new buttons; if one of them was in your toolbar, the new button takes its place. Keyboard shortcuts keep working.
- “Compress …” is now called “Create archive …”.
