**PanePilot 1.6.2** – duplicates by ID, faster meta wizard and small improvements.

## New and changed
- **Find duplicates – new option d) “Same ID in the name”**: groups files by an ID in the file name such as `[imdbid-tt0078748]` or `[tmdbid-348]` (the notation used by Jellyfin, Plex and Kodi). This finds the same film even if the titles are spelled differently, e.g. `Minions and Monsters (2026) [imdbid-tt32890033].mkv` and `Minions Monsters (2026) [imdbid-tt32890033].mp4`.
- **Find duplicates** now shows **how many files were checked**, e.g. “No duplicates found. (0 files checked)” – so you can see immediately when a filter matched nothing.
- **Comma as separator**: several file patterns can now be separated with a comma as well as a semicolon (`*.mkv,*.mp4`) – in the panel filter, in Search and in Find duplicates.
- **Renaming in the “Name (without extension)” column**: F2 now shows the complete name including the extension, so the extension can be changed too. The part before the extension is preselected as before; after Enter the column again shows the name without extension.
- **Meta wizard reads faster**: music and videos are now read several at a time (photos still one after another). Over a network share this should make loading noticeably faster.

## Fixed
- Renaming in the “Name (without extension)” column on an FTP/SFTP server could drop the extension.

## For troubleshooting
- If PanePilot stops responding for a while, it can be started with `PANEPILOT_HANG_LOG=1` (e.g. `PANEPILOT_HANG_LOG=1 ./PanePilot-1.6.2-x86_64.AppImage`). PanePilot then writes `hang.log` to its settings folder (`~/.config/PanePilot/`) whenever the interface is blocked for more than five seconds, showing where it was busy.
