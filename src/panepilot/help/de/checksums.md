# Prüfsummen

**Prüfsummen …** öffnet die Prüfsummen-Seitenleiste. Sie berechnet für die gewählte Datei CRC32, MD5, SHA-1, SHA-256 und SHA-512. Sie folgt dem aktiven Panel: Wählt man eine andere Datei, wird neu gerechnet.

- **Kopieren**: Jeder Wert hat einen eigenen Knopf zum Kopieren.
- **Vergleichen**: eine Prüfsumme, z. B. von einer Download-Seite, in das Vergleichsfeld einfügen. Die Art wird an der Länge erkannt. Grün heißt gleich, rot heißt verschieden.
- **Prüfsummen-Datei**: Eine `.md5`-, `.sha256`- oder `SHA512SUMS`-Datei bzw. eine SFV-Datei lässt sich auf das Vergleichsfeld ziehen, aus Nautilus oder aus PanePilot. Übernommen wird der Eintrag zur gewählten Datei.

Große Dateien brauchen einen Moment. Die Berechnung läuft im Hintergrund, man kann währenddessen weiterarbeiten.
