# Checksums

**Checksums …** opens the checksum sidebar. It calculates CRC32, MD5, SHA-1, SHA-256 and SHA-512 for the selected file and follows the active panel: when you select another file, it calculates again.

- **Copy**: each value has its own copy button.
- **Compare**: paste a checksum, e.g. from a download page, into the comparison field. The type is detected by its length. Green means equal, red means different.
- **Checksum file**: you can drag an `.md5`, `.sha256`, `SHA512SUMS` or SFV file onto the comparison field, from Nautilus or from PanePilot. The entry for the selected file is taken over.

Large files take a moment; the calculation runs in the background and you can keep working.
